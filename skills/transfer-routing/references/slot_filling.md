# 转账提槽规则

用于在 `AG_TRANS` 当前任务已经命中后，提取转账执行所需槽位。

## 必填槽位

- `payee_name`：收款人姓名。
- `amount`：转账金额，输出 `number`，单位默认“元”。

## 提取原则

- 只抽取用户当前输入或当前任务 `source_text` 中明确出现的信息。
- 不得使用常识补全，不得猜测，不得改写用户意思。
- 多轮补槽时保留当前任务已有槽位，只合并最新消息中有依据的新槽位。
- 槽位齐全时返回 `slot_memory` 并让任务进入 `ready_for_dispatch`。
- 槽位缺失时只追问缺失项，不要调用任何工具。

## 收款人姓名

- 抽取用户明确说要转给谁的姓名，如“张三”“李四”“陈广荣”。
- 不要把银行名、家人/朋友/同事称呼、金额当姓名。
- 不带姓氏的名字如果用户明确作为收款人表达，也可以填入 `payee_name`。
- 若用户明确表达“转给本人/转给我自己/转到我账户/给自己转”，且上下文提供了客户本人姓名，则使用客户本人姓名；否则追问收款人。

## 转账金额

- 支持阿拉伯数字和中文数字，例如“一百二”“三千五”“两万”。
- 支持“万/万元/千/百/亿/兆”等换算，例如 `1.5万 = 15000`。
- 如果金额区间或不确定，如“100 到 200”“随便转点”，则不要填写 `amount`，应追问明确金额。
- 输出为 `number`，不要带“元”等单位。

## 不支持场景

如果用户明确表达以下内容，不要填槽为可执行转账，应返回对应说明：

- 外币、跨币种、USDT、外汇：目前仅支持人民币业务，请查找外汇功能。
- 预约、定时、延时转账：仅支持实时人民币转账，预约转账请使用预约功能。
- 明确从非农行卡转出：不支持的转账意图，非农行卡转出。

## Reference 使用

如果仅靠当前消息无法确认收款人，但当前 skill 暴露了收款人列表 reference，可以通过 `requested_references` 请求加载该 reference。不要请求未在可用 Reference 摘要中列出的 reference。
